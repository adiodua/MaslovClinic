# MaslovClinic — API для цен

Бэкенд для админки цен (`/admin/` на сайте). Одна serverless-функция, без
базы данных — она читает и пишет `assets/prices.json` прямо в GitHub-репозитории
сайта. Это тот же самый файл, который каждая страница сайта подгружает,
чтобы показать актуальные цены. Разворачивается точно так же, как уже
работающий API для формы записи (`maslovclinic-booking-api.vercel.app`), на
том же аккаунте Vercel.

## Разворачивание (один раз)

1. Залейте эту папку (`prices-api/`) в отдельный небольшой репозиторий на
   GitHub, либо загрузите её прямо в панели Vercel как новый проект — оба
   варианта работают, сборка (build) не нужна.
2. В Vercel импортируйте её как новый проект. Framework preset: «Other»
   (это просто одна функция в `api/`).
3. В настройках нового проекта Vercel → Environment Variables добавьте:
   - `ADMIN_PASSWORD` — придумайте пароль для админки.
   - `GITHUB_TOKEN` — персональный токен доступа GitHub
     (github.com → Settings → Developer settings → Fine-grained tokens),
     ограниченный только репозиторием сайта MaslovClinic, с правом
     **Contents: Read and write**. Именно этим токеном API коммитит
     изменения цен от вашего имени.
   - `GITHUB_REPO` — `имя_пользователя/имя_репозитория` (репозиторий сайта).
   - `GITHUB_BRANCH` — ветка, из которой публикует GitHub Pages (обычно
     `main`).
4. Задеплойте. Vercel выдаст адрес вида
   `https://maslovclinic-prices-api.vercel.app`.
5. Откройте `admin/index.html` в репозитории сайта и укажите этот адрес в
   константе `API_BASE` в начале блока `<script>`, затем опубликуйте сайт
   как обычно.

## Как изменение цены доходит до сайта

1. Вы открываете `maslovclinic.com/admin/`, вводите `ADMIN_PASSWORD`, меняете
   число, нажимаете «Сохранить и опубликовать».
2. Админка вызывает `PUT /api/prices` на этом бэкенде.
3. Бэкенд коммитит обновлённый `assets/prices.json` прямо в GitHub-репозиторий
   через GitHub Contents API.
4. GitHub Pages подхватывает коммит и публикует сайт заново автоматически —
   обычно за минуту-две, как при любом другом изменении сайта.
5. Скрипт `assets/prices.js` на каждой странице при каждой загрузке заново
   (без кэша) подгружает `assets/prices.json`, так что после публикации новое
   значение появляется везде, где встречается эта цена — на всех 52
   страницах, в обоих языках, включая предложения в тексте, а не только в
   прайс-таблицах.

## Известное ограничение

SEO-метаданные, которые видят поисковики (заголовок страницы `<title>`,
meta description, теги Open Graph, а также структурированные данные
JSON-LD, которые Google использует для показа цены прямо в выдаче) к этой
системе **не подключены** — они прописаны в самом HTML и меняются только
при ручном редактировании и публикации страницы. Это осознанное упрощение,
чтобы админка осталась простой; компромиссы альтернативы (пересборка сайта
из шаблонов, где это ограничение исчезает полностью) описаны в скилле
`multipage-site-architecture-review`.
